# Ultimobiblioteca

Sistema web de gerenciamento de biblioteca desenvolvido em Python com o framework Flask, utilizando arquitetura MVC e banco de dados SQLite.

## Como Executar o Projeto

### Pré-requisitos
* Python 3 instalado na máquina

### Passo a passo

1. **Clone ou baixe o repositório e acesse a pasta do projeto:**
```bash
cd Ultimobiblioteca
```

2. **Crie e ative um ambiente virtual (opcional):**
* **Windows:**
```bash
python -m venv venv
venv\Scripts\activate
```
* **Linux / macOS:**
```bash
python3 -m venv venv
source venv/bin/activate
```

3. **Instale o Flask:**
```bash
pip install flask
```

4. **Execute a aplicação:**
```bash
python run.py
```

5. **Acesse no navegador:**
Abra o endereço `http://127.0.0.1:5000` para utilizar o sistema.

6. **Aproveite o sistema:**
Faça seu cadastro ou login e comece a gerenciar os livros da biblioteca! 😊
